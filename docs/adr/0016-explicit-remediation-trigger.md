# 显式启动泄露凭据处置流程

这个 skill 的执行型处置流程必须由用户显式启动。自然语言中的模糊 Git 历史清理请求只能进入只读澄清和风险说明；任何历史改写、对象回收或推送建议都必须在明确的泄露凭据处置流程中进行。

## 考虑过的方案

- 自动触发完整处置流程：响应更主动，但容易把仓库瘦身、目录删除和凭据事故混在一起。
- 完全不识别自然语言意图：安全但不够有帮助。
- 识别潜在事故并建议显式启动：既能帮用户进入正确流程，又不越过执行边界。

## 后果

- skill 描述必须明确它处理泄露凭据，不处理泛化 Git 清理。
- 模糊请求应先澄清目标，而不是生成 BFG 命令。
- 执行闸门仍然适用于所有历史改写动作。
