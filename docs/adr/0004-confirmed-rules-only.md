# 历史改写只使用确认清洗规则

这个 skill 可以通过只读扫描发现凭据候选项，但不能把扫描结果直接用于历史改写。只有用户明确确认的凭据值、文件路径或匹配规则，才能成为确认清洗规则并进入执行计划。

## 考虑过的方案

- 自动扫描后直接清洗：速度快，但误报会造成不必要的历史改写，漏报会制造错误安全感。
- 完全依赖用户手写规则：安全边界清晰，但定位效率低，容易遗漏候选。
- 自动扫描产出候选，用户确认后清洗：兼顾发现能力和执行安全。

## 后果

- skill 展示候选时必须脱敏，避免二次泄露。
- 执行计划必须列出使用了哪些确认清洗规则。
- 验证阶段必须验证确认清洗规则不再出现在目标历史中，而不是笼统宣称“仓库干净”。
