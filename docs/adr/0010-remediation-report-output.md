# 默认以对话摘要交付，按需导出处置报告

这个 skill 默认在对话中交付处置摘要，而不是自动写入目标仓库或生成报告文件。只有用户明确要求落盘时，skill 才生成 Markdown 处置报告；报告内容基于处置摘要扩展，并且不得暴露完整泄露凭据。

## 考虑过的方案

- 只输出命令结果：实现简单，但缺少事故处置所需的审计上下文。
- 默认生成 Markdown 报告文件：便于留档，但可能被误提交到目标仓库或暴露事故上下文。
- 默认输出对话摘要，按需导出报告：降低落盘风险，同时保留留档能力。

## 后果

- skill 需要在每个阶段积累摘要素材。
- 处置摘要必须区分已完成事项、用户仍需执行的事项和未覆盖风险。
- 用户要求导出报告时，报告文件中的凭据内容必须脱敏，避免二次泄露。
