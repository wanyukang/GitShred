# 扫描器只作为可选只读候选发现器

GitShred 第一版不依赖 gitleaks、trufflehog 或其他 secret scanner。若这些工具已经存在于用户环境中，skill 可以调用它们做只读候选发现；扫描结果必须经过用户确认后，才能成为确认清洗规则。

## 考虑过的方案

- 强依赖 secret scanner：候选发现更强，但安装、规则库和输出格式都会增加失败模式。
- 完全不使用 scanner：边界清晰，但会降低未知泄露场景中的发现能力。
- 已安装则可选使用：保留发现能力，同时避免把 scanner 变成第一版依赖。

## 后果

- 没有 scanner 时，GitShred 仍可基于用户提供的规则完成处置。
- scanner 未发现候选，不能被解释为仓库没有泄露凭据。
- scanner 输出不能直接驱动 BFG，必须经过用户确认。
