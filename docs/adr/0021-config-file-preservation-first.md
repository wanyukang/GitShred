# 配置文件默认保留并替换凭据

对 .env、YAML、JSON、properties 和连接串等混合配置文件，GitShred 默认保留文件结构，只替换用户确认的 password、Token 或其他凭据。只有用户明确选择“删除整个文件”并在执行前再次确认破坏性后果时，才使用文件级删除；纯凭据文件可以在确认后建议整体删除。

## 考虑过的方案

- 按文件名直接删除 .env：实现简单，但会丢失非敏感配置，也不一定符合用户的业务目标。
- 对所有文件只做文本替换：保留结构，但不适合私钥或纯凭据文件。
- 配置文件保留优先，纯凭据文件可删除：按文件语义选择动作，并要求用户明确确认整体删除。

## 后果

- “清理 .env”直接进入保留文件、替换凭据的默认路径，不要求用户先在删除和替换之间二选一。
- Agent 需要先展示配置文件中的凭据候选，再生成 text 规则并请求确认。
- file 规则不能仅因为文件名是 .env 就自动生成；任何文件删除都必须经过单独的二次确认。
