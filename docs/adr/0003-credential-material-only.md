# 只处理泄露凭据，不处理一般 PII 或泛化业务机密

这个 skill 将“敏感信息”收窄为泄露凭据，包括密码、Token、私钥、访问密钥和其他认证材料。它不处理一般 PII、业务机密文本、普通邮箱地址、客户资料或难以精确识别的自然语言内容。

## 考虑过的方案

- 覆盖所有敏感信息：看起来能力更完整，但会引入合规判断、误删风险和难以验证的自然语言分类问题。
- 只处理泄露凭据：范围更窄，但检测、改写、轮换提醒和验证闭环都更清晰。

## 后果

- skill 的审计问题应围绕“凭据类型、匹配方式、是否已轮换、历史中是否残留”展开。
- PII 删除、合规擦除和业务机密清理应由其他流程处理。
- 文档与提示词中应避免把该 skill 描述成通用敏感数据清理工具。
