# 只支持文本替换和敏感文件删除

第一版只允许两类 BFG 清洗动作：替换已确认的 secret 文本，以及删除已确认的敏感文件。仓库瘦身、泛化目录删除、模糊内容分类和自动推断替换规则都不属于第一版范围。

## 考虑过的方案

- 暴露 BFG 的所有能力：灵活，但会把仓库维护、目录清理和事故处置混在一起。
- 只支持文本替换：范围最窄，但无法处理误提交私钥文件或环境文件的常见事故。
- 支持文本替换和敏感文件删除：覆盖常见泄露凭据场景，同时保持能力边界清晰。

## 后果

- 执行计划必须把每条确认清洗规则映射到文本替换或敏感文件删除。
- 任何仓库瘦身类请求都应被拒绝或引导到其他工具流程。
- 删除文件时必须确认目标是敏感凭据文件，而不是普通业务目录。
